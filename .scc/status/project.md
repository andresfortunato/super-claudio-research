# research-to-policy

A Claude Code harness for applied empirical, data-analytical, and policy research — adapts scc's planning/handoff/verification discipline to the realities of policy research and applied development economics.

**Current focus: `plan/plan-r2p-v3` — checking the citation chain.** v3's thesis is that v2 established a `deliverable → claim → evidence → artifact → script → source` chain and checked almost none of it. **Phases 1 through 6 are done and all researcher decisions are answered.** `lint-research.sh` has gone from 7 checks to **18** and from **11.0s to 2.3s** on the pilot, `.next-id` acquired the first tool that reads it (`r2p evidence new`), `/cite-check` walks the half of link 1 no grep can see, `/pipeline-check` re-runs an evidence doc's producing script and diffs the numbers against `## Measured`, and the second installer finally has an integration test (`npm test`).

**Next: Phase 7 — docs, constitution, release. The only phase left.** Unblocked. **Phase 6 landed all six items 2026-09-09** (`6a0086d` … `d195621`; see `plan/plan-r2p-v3/log.md` D9). New lint invariants **15–18**: an in-repo doc pointer that resolves to nothing, a claim resting on retracted evidence, a claim with no ids, and the ids in a claim's `Contested by:` / `Supersedes` legs. **Invariant 15 is what makes Phase 7's documentation deletion safe** — deleting a `docs/*.md` turns every pointer at it into a reported defect, so the citation sweep has a green condition instead of a hand-built list.
