# Evidence Index

Project-level evidence from your data analysis (chart-backed numbers,
regression results, headline findings). One row per evidence doc. Numbering
is sequential across all plans/phases — append, never renumber.

For flat layouts, omit the `Theme` column entirely. For theme-parallel
projects (multiple parallel lines of inquiry, each in its own
`evidence/<theme>/` subfolder), keep the column and link relative paths
from `INDEX.md` (`[Title](spatial-equilibrium/01_slug.md)`). See
`.claude/conventions/evidence-logging.md` for the opt-in pattern.
