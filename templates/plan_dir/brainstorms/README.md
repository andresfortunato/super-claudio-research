# plan/brainstorms/

Decisions-pre-planning. Output of the `brainstorming` skill.

One file per topic: `plan/brainstorms/<topic>.md`. Theme-parallel projects may
use `plan/brainstorms/<theme>/<topic>.md`. Gitignored — durable enough to
reference within a session, transient enough not to ship in the repo.
Methodology calls that should outlive the brainstorm graduate to
`research/methods/<topic>.md`.

Format and handoff to the planning skill: `.claude/conventions/plan-lifecycle.md`.
Rationale: `docs/brainstorm-mechanism.md`.
