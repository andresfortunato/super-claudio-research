# Analysis craft — cross-cutting numerical and reasoning traps

**One file, deliberately.** These traps have no single methodological home, and
giving each its own file is how earlier r2p versions grew a 70-entry `research/methods/`
directory. If an entry becomes specific to one method, move it into that topic's
`## Traps`.

Format: `## <the trap as a claim>` then symptom, then fix.

## <Example — two upside margins each worth ×2 sum to ×3, not ×4>
<Symptom, then the fix, with the number that made it visible.>
