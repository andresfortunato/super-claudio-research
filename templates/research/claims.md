# Claims ledger

**Last reviewed:** <YYYY-MM-DD> against evidence #<n>.

**Mandatory once `research/evidence/` passes 40 docs.** Below that the capped
`INDEX.md` is still a usable triage surface and this file is overhead.

~30–50 claims, grouped in the order your narrative uses them. Deliverables cite
claims; claims cite evidence. This file is **editable and deletable** — it is a
curated view, not a record. `research/evidence/` underneath it is append-only.

`Contested by:` is an open question, not a footnote. Never soften a claim's
wording until both sides fit: that buries the disagreement and it resurfaces in
the next deck.

Protocol: `.claude/conventions/claims.md`.
